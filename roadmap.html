SSO Platform — Build Roadmap

Checklist bertahap dari nol sampai production. Centang item yang selesai — progres tersimpan otomatis di browser. Stack: Next.js 16.3.x · Ory v26.2.0 · Traefik v3.7 · pnpm 12 · Postgres 17.

Transport Layer Security — enkripsi HTTPS
ACME
Automatic Certificate Management Environment — protokol auto-renew sertifikat (dipakai Let's Encrypt)

Simple Mail Transfer Protocol — protokol kirim email
OPL
Ory Permission Language — bahasa definisi namespace Keto
RBAC
Role-Based Access Control — otorisasi berbasis role
MFA
Multi-Factor Authentication — autentikasi berlapis
TOTP
Time-based One-Time Password — kode authenticator (Google Authenticator, dsb.)
JWKS
JSON Web Key Set — endpoint publik berisi kunci verifikasi token
CRUD
Create, Read, Update, Delete
CI/CD
Continuous Integration / Continuous Delivery
WAF
Web Application Firewall
SSRF
Server-Side Request Forgery — serangan via request server-side
HMR
Hot Module Replacement — reload otomatis saat dev
